# Лабораторная работа: вариант 20

В проекте одна запускаемая программа с выбором метода и действия в терминале:

1. Таблица Трисемуса (метод 5).
2. Двойная табличная перестановка (метод 10).

Вариант 20 использует алфавит из 35 символов: `А…Я`, пробел и точку. Буква `Ё` включена, чтобы состав алфавита соответствовал указанному в таблице задания количеству символов.

## Запуск в VS Code

1. Откройте в VS Code папку `Вариант20_Java` целиком.
2. В Explorer выберите файл `Main.java` в корне проекта.
3. Нажмите **Run Java** над методом `main`.
4. Выберите метод `1` или `2`, затем действие: `1` — шифрование, `2` — расшифровка.

Из терминала проекта программу можно собрать и запустить так:

```powershell
javac -encoding UTF-8 -d out Main.java
java -cp out Main
```

## Файлы проекта

- `data/input.txt` — исходный текст для шифрования.
- `data/key_trisemus.txt` — ключевое слово таблицы Трисемуса.
- `data/keys_double.txt` — два ключа двойной перестановки: сначала ключ столбцов, затем порядок строк.
- `data/result_trisemus.txt` — только шифртекст Трисемуса. Метод 1 шифрует текст из `input.txt` и записывает результат сюда. Для расшифровки выберите метод 1 и действие `2`: программа возьмёт шифртекст из этого файла и оставит его без изменений.
- `data/result_double_transposition.txt` — только шифртекст двойной перестановки. Метод 2 шифрует текст из `input.txt` и записывает результат сюда. Для расшифровки выберите метод 2 и действие `2`: программа возьмёт шифртекст из этого файла и оставит его без изменений.

Для двойной перестановки первый ключ задаёт столбцы: они сортируются по символам ключа в алфавитном порядке. Второй ключ задаёт порядок строк. Например, `3124` означает, что строка 3 идёт первой, затем строки 1, 2 и 4. Длина первого ключа задаёт число столбцов, длина второго — число строк. Программа шифрует первую полную часть алфавита размером с таблицу, находит индексы символов в получившейся зашифрованной версии алфавита и применяет этот порядок к каждому блоку исходного текста. Поэтому отдельная перестановка для текста не вычисляется. В неполном последнем блоке берутся только индексы, для которых есть символы; пустые ячейки не добавляются в шифртекст. Размер таблицы должен помещаться в алфавит варианта 20.

Для Трисемуса расшифровка использует обратную таблицу замены. Для двойной перестановки программа восстанавливает символы по обратному порядку индексов, включая неполный последний блок. При расшифровке открытый текст показывается в консоли, а файл с шифртекстом остаётся без изменений. Таблицы выводятся строками без рамок; пробел в таблице обозначается символом `_`.

Текст приводится к верхнему регистру. Допускаются только символы заданного алфавита. Внутренние переводы строк и другие символы программа отклоняет с сообщением об ошибке.
